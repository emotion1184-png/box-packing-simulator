- ✅ **자체 3D Bin Packing 알고리즘 구현**

- ✅ 높이 방향 적치 완벽 지원

## 📊 **알고리즘 상세**

### **Guillotine 3D Packing**
1. **초기 상태**: 포장박스 전체가 1개의 빈 공간
2. **박스 배치**: 가장 작은 공간에 우선 배치 (Best Fit)
3. **공간 분할**: 배치 후 남은 공간을 3방향으로 분할
   - L 방향 (오른쪽)
   - W 방향 (앞쪽)
   - **H 방향 (위쪽)** ← 중요!
4. **반복**: 모든 박스가 배치될 때까지

### **회전 지원**
- 회전 허용 제품: 6가지 방향 자동 시도
- 회전 금지 제품: 원래 방향만 사용
